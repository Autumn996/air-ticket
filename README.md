# 上海假期机票

## GitHub Pages 看板

[手机版看板](https://autumn996.github.io/air-ticket/)显示公开参考价、报价历史和已采集的航班摘要。GitHub Actions 每天北京时间 09:07 采集并发布，也可在工作流页面手动运行。`state/fares.sqlite3` 保存云端报价历史，SerpApi 密钥由仓库的 `SERPAPI_API_KEY` Actions Secret 提供。按需查询、关注记录和人数核价在本机版使用。

## Windows 本机版

双击 [启用每日监控.cmd](./启用每日监控.cmd)，在本机窗口输入 [SerpApi 密钥](https://serpapi.com/manage-api-key)。脚本验证密钥、采集首批价格，并创建 Windows 任务 `Shanghai Holiday Fare Monitor` 和 `Shanghai Holiday Fare Details`。密钥由当前 Windows 账户加密保存。密钥请留在本机。

打开 [机票看板.html](./机票看板.html)，按节假日跳转，再展开想看的出发和返程日期。表格按当次报价从低到高排列。顶部的“历史记录”可按往返日期和目的地查看全部采集日的报价，包括已停查或已结束的行程。积累至少三天历史报价后，同一目的地和日期组合比近期中位价便宜 15% 时会有提示。

“航班详情”显示已配对的去程和返程、各自起降时间、机场、航班号、飞行时长和该组合的往返报价。可按价格和抵达时间排序，按上海出发机场或去程当天抵达筛选，并展开查看同一组航班已采集的历史票价。每天在额度内轮查未取得明细或最久未更新的城市，额度充足时也刷新一个低价候选。可在详情页点“查询往返方案”按需查询，每次给出至多两个去程及其返程候选。按需详情由本机服务 `127.0.0.1:8767` 提供，登录 Windows 时启动。每次按需查询会使用最多三次 SerpApi 搜索，程序会预留本期每日比价所需额度。

“选去哪”在同一组出行日期下跨城市比较已核对的航班。可按预算、浦东或虹桥、是否当天抵达、起降时间和停留长短筛选。“避开红眼航班”会排除任一程跨日抵达，或在当地时间 23:00 至次日 06:00 前起降的组合。可按单人机票、落地停留时间或全员整趟估算排序。住宿、交通和其他费用由你填写并保存在本浏览器。未填住宿或交通的城市会标为费用待补。页面显示当天已核对的覆盖范围，每次可按参考价顺序补查最多两个城市。

在「选去哪」或「航班详情」点击「关注此往返」，可保存实际航班并设单人往返目标价。现有每日任务会优先核对已关注的具体组合，每天最多自动核对两套，数量较多时按上次核价时间轮询。页面保存每日核价记录，当天报价达标时会在「关注航班」及看板上显示。来源无有效报价时，会保留上次有效报价的日期。

同样可以点「按人数核价」，为指定航班查询 1–9 位成人的全员往返报价。有当天报价的组合会在「选去哪」按所选人数计入整趟估算，其他方案沿用单人价乘人数。重复核对同一组合和人数时，一小时内会复用缓存。

每天 09:00 运行。电脑需开机、联网且当前 Windows 账户已登录。错过时由任务计划程序在条件允许后补跑，记录补跑当天的价格。手动刷新采集可以在项目目录运行 `python -X utf8 monitor.py collect`。当天成功查询过的日期组合会沿用当天记录。运行结果会显示在看板，详细状态保存在 `data/monitor.log`。

监控浦东和虹桥出发的国内直飞，按 1 位成人经济舱往返的人民币参考价比较。每次查询覆盖数据源返回的多个目的地。每天查未来 120 天内最近的两个已配置假期，每个最多三组日期，每月定时查询最多 186 次。SerpApi 当前免费档每月 250 次。同一账户其他应用的用量也会占用额度。

放假日期来自[国务院办公厅 2027 年放假通知](https://www.gov.cn/zhengce/content/202611/content_7085101.htm)。在 `holidays.json` 中设置 `planned_trip` 可指定行程日期，设置 `paused` 为 `true` 可暂停该假期。下一年度的通知公布后，可把日期追加到同一个文件。报价保存在 `data/fares.sqlite3`，复制此文件即可备份历史记录。可在 Windows 任务计划程序中禁用该任务以暂停全部采集。
